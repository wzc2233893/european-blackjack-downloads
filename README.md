## 安装

**安卓：** Android 7.0 及以上，支持 ARM 32/64 位手机。下载 APK 后打开安装，按系统提示允许当前浏览器或文件管理器安装应用。横屏游玩。此包不适用于 iPhone。

**电脑：** Windows 10/11 64 位。下载安装程序并运行，按提示完成安装；可选择创建桌面快捷方式。安装在当前用户目录，无需管理员权限。安装包未购买 Windows 代码签名证书，系统可能显示发布者未验证提示。
